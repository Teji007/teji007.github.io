# Vaurypt Project Page

A polished static landing page for **Vaurypt**, the Windows encryption/backup project by **Tejinder Pal Singh**.

## Included

- `index.html` — landing page
- `styles.css` — responsive dark/glass visual system
- `script.js` — feature filtering and lightweight reveal animation
- `assets/vaurypt-logo.svg` — logo/favicon
- `assets/architecture.svg` — security architecture graphic
- `assets/vaurypt-ui.png` — cropped application UI screenshot

## GitHub Pages

1. Put these files in a repository or `/docs` folder.
2. In GitHub, open **Settings → Pages**.
3. Choose the branch containing this page and the root folder (or `/docs` if you placed it there).
4. Save the Pages configuration.
5. Wait for the site to publish.

The page links currently point to:
- GitHub: `https://github.com/Teji007/Vaurypt`
- Latest release: `https://github.com/Teji007/Vaurypt/releases/latest`

Update those URLs if the repository address changes.
